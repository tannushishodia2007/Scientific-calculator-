    How it works

    1. Tokenizer. The typed text is split into numbers, operators, functions and brackets.

    2. Shunting-yard. The tokens are reordered into postfix form using operator precedence, so 2+3×4 becomes 2 3 4 × +. That is how BODMAS is followed.

    3. Stack evaluation. The postfix list is solved from left to right using a stack. No eval() is used.

    Keyboard: 0-9 . + - * / ^ ( ) ! %, Enter for equals, Backspace to delete, Esc to clear.
